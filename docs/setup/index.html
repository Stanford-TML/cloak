The setup sequence

Start with a complete working DROID system. Assemble your end effector, confirm Franka Desk settings, configure the workstation and NUC, calibrate the wrist camera, then run a supervised policy and inspect its mask recording.

Robotiq can stay mounted when it already follows DROID. UMI reuses its camera mount in a different orientation. Sharpa uses a dedicated bracket and angled adapter.
